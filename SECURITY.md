# Security Policy

Security issues should be reported privately.

Do not disclose suspected vulnerabilities, credentials, client information, or sensitive technical details through public GitHub Issues, Discussions, or pull requests.

If GitHub Private Vulnerability Reporting is enabled for the affected repository, use that mechanism. Otherwise, contact an Oferli organization owner through an approved private communication channel.

When reporting an issue, include where possible:

- affected repository or service
- description of the issue
- steps to reproduce
- potential impact
- suggested remediation, if known

Do not include real credentials, customer data, production dumps, or other sensitive information unless a secure communication channel has been established.

Oferli will review reported security issues and coordinate remediation and disclosure where appropriate.
